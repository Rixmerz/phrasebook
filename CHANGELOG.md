## [0.1.0] - 2026-10-28

First tagged version: the engine, proxy and benchmark as of the glossary v4 rounds.

### Added
- `docs/field-report-gemini-data-agent.md`: anonymized field report of a phrasebook
  port to a production text-to-SQL agent on Gemini Flash-Lite, the first evidence
  outside Claude models. Tokens per turn -21% (noise 11%), rounds unchanged; data
  glossaries that replace discovery saved 12% and lowered graded quality. Explains
  the gap with the GitHub results and lists lessons for porting.
- Results row in `README.md` and a summary section in `docs/RESULTS.md`.
